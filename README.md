
# Projeto Data Warehouse - Transações de Cartão

## Objetivo
Construir um Data Warehouse a partir de dados de faturas de cartão de crédito, aplicando ETL e análises.

## Tecnologias
- Python (pandas)
- SQLite
- SQLAlchemy

## Estrutura
- etl/: scripts ETL
- sql/: criação de tabelas e queries
- data/: arquivos CSV

## Execução
1. Instale dependências:
   pip install -r requirements.txt

2. Coloque os CSVs na pasta data/

3. Execute:
   python etl/main.py

Veja sql/queries.sql
